# Дизајн систем — Право на длану

Жива референца је на `/dizajn-sistem`. Приказ користи стварне компоненте апликације; не одржавамо посебне копије дугмади или поља за документацију.

## Извори истине

- `src/app/design-tokens.css`: семантичке боје, фонтови, размаци, радијус и мере.
- `src/app/globals.css`: повезивање токена са Tailwind класама и shadcn/ui скалом радијуса.
- `src/components/ui/`: shadcn/ui компоненте, стил `base-nova`, на Base UI.
- `src/app/site.css`: обрасци каталога, мапе, читача, учења и странице о пројекту. Боје, фонтови, радијуси и основни размаци користе заједничке токене. Геометрија мапе, скенови и корисничка подешавања читача задржавају своје мере.
- `src/app/dizajn-sistem/`: приказ основа, интерактивних стања и правила садржаја.

Компоненте се увозе из `@/components/ui/`. За линк који изгледа као дугме користити `buttonVariants`; за Base UI окидаче композицију `render={<Button />}`. Не користити Radix `asChild` API.

## Визуелни језик

Топао папир, тамно мастило и теракота настављају постојећи идентитет. Главне радње су тамне, а теракота наглашава бренд и фокус. Не уводити нове стилове дугмади, поља, избора и ознака за појединачне странице.

| Улога                      | CSS токен                               | Светла тема           |
| -------------------------- | --------------------------------------- | --------------------- |
| Позадина                   | `--background`                          | `#faf9f6`             |
| Текст                      | `--foreground`                          | `#282824`             |
| Картица / поповер          | `--card`, `--popover`                   | `#fffefa`             |
| Главна радња               | `--primary`                             | `#292d28`             |
| Текст главне радње         | `--primary-foreground`                  | `#fffefa`             |
| Бренд / фокус              | `--brand`, `--ring`                     | `#963e35`             |
| Пратећа површина           | `--muted`, `--secondary`                | `#eeede8`             |
| Пратећи текст              | `--muted-foreground`                    | `#686b60`             |
| Ивица                      | `--border`                              | `#e3e1d9`             |
| Ивица поља                 | `--input`                               | `#dbd9d1`             |
| Уредничка површина / текст | `--editorial`, `--editorial-foreground` | `#eff0e7` / `#536145` |
| Упозорење / текст          | `--warning`, `--warning-foreground`     | `#f8eee3` / `#80502e` |
| Грешка / уклањање          | `--destructive`                         | `#b3261e`             |

Боје увек користити у семантичким паровима. `primary` иде уз `primary-foreground`, `card` уз `card-foreground`, итд. `.dark` садржи одговарајуће токене за компоненте и приказан је изолован узорак. Сајт нема прекидач тамне теме; читач, скенови и мапа захтевају засебну проверу пре његовог увођења.

## Типографија и простор

| Намена              | Фонт / токен                                         | Величина / проред                     |
| ------------------- | ---------------------------------------------------- | ------------------------------------- |
| Интерфејс           | Arial, Helvetica, sans-serif / `--type-ui`           | 14 px / 1,6                           |
| Уводни наслов       | Georgia, Times New Roman, serif / `--type-editorial` | 44 px / 1,2; прилагодити уском екрану |
| Наслов одељка       | `--type-ui`                                          | 24 px / 1,2                           |
| Текст прописа       | `--type-editorial`                                   | подразумевано 16 px / 24 px           |
| Метаподаци          | `--type-ui`                                          | 12 px / 1,6                           |
| Називи токена / код | Consolas, Liberation Mono, monospace / `--type-code` | 11–12 px / 1,6                        |

Фонтови су системски и подржавају ћирилицу; нема спољних захтева за фонтове. `font-heading` остаје интерфејсни фонт за дијалоге и контроле. За уреднички наслов користити `font-editorial` или `--type-editorial`.

Размаци: `--space-1/2/3/4/6/8/12/16` одговарају 4/8/12/16/24/32/48/64 px при основном фонту од 16 px. Tailwind `gap-4` и `p-6` користе исту скалу. Основни `--radius` је 0,55 rem (8,8 px); `sm/md/lg/xl` су 0,6/0,8/1/1,4 пута та вредност. Не мењати локално величине контрола: постојеће Button варијанте су 24/28/32/36 px, а Input и Select подразумевано 32 px.

Мера од `72ch` је полазиште за нове текстуалне приказе. Постојећи читач задржава своја подешавања величине слова и прореда, као и широке правне табеле.

Каталог користи исти Input као приказ компоненти; икона и дугме за брисање су распоређени око њега без замене његове ивице или стања фокуса. Мапа користи `brand`, `editorial-foreground`, `editorial-border` и `border`, а ознаке области `chart-1/2/3/4`. Боја области је оријентациона; назив је увек приказан. Мобилна навигација остаје обична група линкова, доступна и у самосталним HTML документима без JavaScript-а. Белина скениране странице и штампе намерно је независна од теме.

## Компоненте и стања

| Компонента | Када је користимо         | Обавезна стања и садржај                                                          |
| ---------- | ------------------------- | --------------------------------------------------------------------------------- |
| Button     | Радња                     | default, outline, secondary, ghost, destructive, link; фокус, disabled, учитавање |
| Input      | Унос и претрага           | Видљив label, опис, вредност, празно, грешка, disabled                            |
| Select     | Избор једне ставке        | Назив, изабрано, отворено, фокус, disabled                                        |
| Badge      | Метаподатак               | default, secondary, outline, destructive; није интерактивни филтер                |
| Tabs       | Сродни прикази            | Стрелице померају фокус; Enter или размак активира картицу                        |
| Accordion  | Допунски садржај          | Јасан наслов, отворено/затворено; важне напомене остају видљиве                   |
| Dialog     | Кратка одлука или порука  | Title, Description, затварање, Escape, повратак фокуса                            |
| Sheet      | Контекстуални бочни панел | Исто управљање фокусом као Dialog; приступачан на уском екрану                    |
| Tooltip    | Кратка допуна             | Доступан на фокус; није једино место за важну информацију                         |
| Separator  | Раздвајање група          | Одговарајућа оријентација и размак                                                |

Текст интерфејса и приступачни називи су на српској ћирилици. Претрага користи `normalizeSearch` / постојећу претрагу каталога, прихвата латиницу и унос без дијакритика. Иконска дугмад имају `aria-label`. Грешка поља има `aria-invalid` и повезан опис. За контроле додиром обезбедити довољно размака и проверити циљеве у контексту.

## Садржај и поверење

1. **Текст прописа:** непромењен текст са ПИС извором, стварном верзијом, датумом приступа и експлицитним обухватом. Извод не називати целим законом.
2. **Уредничко објашњење:** визуелно одвојено и јасно означено. Повезати са прописом; не уметати га у цитат.
3. **Измишљен пример:** ознака пре сценарија, питање, повратна порука и извор. Нови примери припадају `content/learning.json`.

Боја не доказује правни статус. Датум приступа није датум правне провере. Дизајн систем не мења корпус, изворну политику нити обухват збирке.

## Фигма

Референца: [@shadcn/ui — Design System, Pietro Schirano](https://www.figma.com/community/file/1203061493325953101/shadcn-ui-design-system). Прегледано 6. новембра 2026. Опис датотеке наводи Radix UI и Next.js 13, док пројекат користи Base UI, base-nova и Next.js 16. Зато библиотека служи као визуелно полазиште; за димензије и понашање меродаван је локални приказ. Нова Figma датотека није креирана овом изменом.

За пратећу Figma библиотеку:

1. У копији референце задржати ауторство и услове њене лиценце.
2. Организовати странице: „Основе“, „Компоненте“, „Обрасци“, „Екрани“.
3. Креирати колекцију `Pravo` са семантичким именима `background`, `foreground`, `primary`, `primary-foreground`, `brand` итд. Имена директно одговарају CSS променљивама без префикса `--`.
4. Подесити текстуалне стилове и бројчане променљиве за размаке и радијус према табелама изнад. Светли режим је основни; тамни је тренутно референца за компоненте.
5. Ускладити компонентне варијанте са локалним пропсима `variant` и `size`. Укључити нормално, hover, focus, disabled, invalid и loading стање где је применљиво.
6. Користити Auto Layout, дугачке ћириличне наслове, Lucide иконе и текстуалне ознаке. Проверити 390 px и широки екран, увећање текста и прелом.

Семантички модел прати [shadcn/ui theming документацију](https://ui.shadcn.com/docs/theming). При промени токена ажурирати овај водич и проверити жива стања, каталог, читач и статички извоз. Не инсталирати shadcn CLI без прегледа зависности; политика зависности је у README-у.
