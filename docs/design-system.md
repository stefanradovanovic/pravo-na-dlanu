# Дизајн систем 2 — Право на длану

Жива референца: `/dizajn-sistem`. Она користи стварне компоненте апликације.

## Одобрени правац

Корисник је изабрао трећи концепт, „Reading Desk“, и затражио обнову система уз AI for UI и UI SDK. [Изабрана слика](design/reading-desk.png) је визуелна референца. Тамно заглавље даје оријентацију, светла бочна површина садржај документа, а бела површина простор за читање.

Ово је једини забележен избор укуса; не подразумева склоност ка Apple материјалима, општу тамну тему или анимиране странице. Приказ задржава стварни увод, напомене и цео текст ПИС-а који су изостављени у концептној слици.

## Извори истине

| Датотека                            | Одговорност                                             |
| ----------------------------------- | ------------------------------------------------------- |
| `src/app/design-tokens.css`         | Семантичке боје, типографија, простор, мере и кретање   |
| `src/app/globals.css`               | UI SDK слој, Tailwind и локални фонтови                 |
| `src/app/components.css`            | Стилови и стања заједничких контрола                    |
| `src/components/ui/`                | Познати shadcn/ui интерфејси компоненти, сада на UI SDK |
| `src/app/reading-desk.css`          | Заглавље, каталог и читач; прилагођавање ширини екрана  |
| `src/app/site.css`                  | Преостали обрасци учења, мапе, извора и факсимила       |
| `src/app/dizajn-sistem/`            | Живи примери истих компоненти                           |
| [Примена вештина](design/skills.md) | Преглед свих AI for UI вештина и правила примене        |

Пре измене UI SDK компоненте прочитати њену документацију у инсталираном пакету. Увозити по компонентним улазима, нпр. `@ui-sdk/react/dialog`. Локални `Button`, `Input`, `Tabs` и други остају јавни интерфејс апликације. Композиција користи `render`, не `asChild`. Не покретати генератор који би преко ових адаптера вратио Base UI имплементацију.

UI SDK је закључан у package-lock датотеци на `0.1.0-beta.1`. Надоградње захтевају проверу SSR-а, статичких острва, тастатуре и фокуса. Не користимо његов опциони web.css јер би увео други визуелни систем.

| --------------------- | ----------------------------- | ---------------------------------------------------- |

| Код и токени          | Consolas, системски monospace | 12–13 px                                             |

Fontsource пакети служе фонтове локално, са unicode-range подскуповима за ћирилицу и латиницу и `font-display: swap`. Нема захтева ка Google Fonts при читању. Обе породице су OFL; лиценце су у инсталираним пакетима.

Основа размака је 4 px, скала 4/8/12/16/24/32/48/64. Основни радијус је 6 px. Подразумевана контрола је висока 44 px; компактна 36 px на прецизном показивачу и најмање 44 px на додиру. Поља су најмање 16 px на додирним екранима. Читач има ограничење од 65ch, бочни садржај 21rem и прелаз у склопиви мобилни садржај испод 1024 px. Кратки екрани не користе лепљиви садржај.

## Понашање

| Образац                             | Правило                                                               |
| ----------------------------------- | --------------------------------------------------------------------- |
| Претрага, картице, прелазак на члан | Непосредна промена, без анимације садржаја                            |
| Боја контроле                       | 100 ms; само color, background-color, border-color                    |
| Дијалог                             | 200 ms opacity/scale; ease-out; фокус у дијалогу и повратак на окидач |
| Бочни панел                         | 200 ms transform/opacity; исти смер отварања и затварања              |
| Умањено кретање                     | Без прелаза и позиционог померања                                     |
| Савети и допунски садржај           | Непосредно; важна информација није само у tooltip-у                   |
| Обавештење о копирању               | Текст и икона уз радњу, role=status; без toast зависности             |

Користити hover само на уређајима који га имају. Не анимирати законе, резултате претраге или дуге листе. Нема `transition-all`, украса при учитавању, spring библиотеке, прилагођеног повлачења или swipe навигације.

Управљана UI SDK поља користе `onValueChange`, тако да тастатура и агент мењају исто стање. У развоју `UIAgentBridge` региструје локалне WebMCP алате ако их прегледач подржава. Означена радња брисања напретка не може да се изврши кроз тај мост без човека. Мост није укључен у продукцију; нема спољног AI сервиса.

## Читач и поверење

- Изворни Markdown остаје један цео закон. Правни текст се не хидрира, не виртуализује и не мења због дизајна.
- Контроле су мала одвојена React острва. Избор величине мења CSS променљиве, не садржај.
- Бочни садржај користи native details и стварне fragment линкове: доступан је пре хидрације и без JavaScript-а. JS додаје филтер, праћење члана и фокус на одредишту.
- Наслови чланова долазе из истог опрезног правила које већ приказује поднаслове у документу. Дупли бројеви задржавају различите адресе.
- Верзија извора, датум приступа, обухват и ПИС линк су увек уз наслов. Датум није правна потврда важења.
- Уреднички примери имају засебну ознаку и склопиву целину. Њихова напомена је пре сваке приче. Пример није део закона.
- Штампа задржава текст и порекло, а уклања контроле и уредничке примере.
- Мобилна навигација задржава стварне линкове, safe-area простор и могућност увећања странице.

## Промена и провера

За нову страницу прво изабрати постојећи образац и семантичке токене. Нову варијанту компоненте додати само када постојећа не може да изрази њену улогу, па је приказати у живој референци. Figma библиотека може пратити иста имена токена; ова измена не креира Figma датотеку.

Проверити каталог, учење, читач и живу референцу, тастатуру, фокус, 320/390 px, дугачак наслов, верзију и велики садржај. Покренути `npm test`, `npm run typecheck` и `npm run build`. Поређење са концептом, стања и преостала ограничења бележе се у коренском `design-qa.md`.
